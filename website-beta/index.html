CONNECTION

Game server

Hostname
game.twclone.impara.co.uk
Game port
12483
Transport
Direct TCP with TLS. Certificate and hostname verification are required.

The game hostname must use a DNS-only record so the raw game protocol reaches the game service directly. The website uses HTTPS separately; its HTTP proxy does not carry game traffic.

FIRST FLIGHT

Register, log in and begin

  1. Download and unpack one client. Install Python 3.9+ or Godot 4.5.2 as described above.
  2. Connect to game.twclone.impara.co.uk on port 12483 with verified TLS enabled.
  3. Choose Create account, select a captain name and password, then log in with that account.
  4. Check your ship, credits and turns before leaving the starting sector.

Do not send passwords in bug reports or public messages. The game service is not live until this page says the beta is open.

QUICK GUIDE

Make your first moves

Move

Scan the current sector, inspect connected warps and plot a route. Each warp spends turns; avoid spending them on loops without a reason.

Trade

Dock at a port and read its buy/sell directions before trading. Watch your cargo holds, credits, turns and changing stock.

Planets

Use a Genesis torpedo to create a planet where permitted. Land to transfer colonists, assign workers and harvest stored production.

Corporations

Create or join a corporation, check member permissions and use the treasury and shared-asset actions deliberately.

Combat

Check target eligibility and your ship's shields, fighters and weapons. Retreat when the situation turns against you; losses require recovery.

BETA NOTES

Release notes and known limitations

  • V3 targets original TradeWars 2002 gameplay parity with project-specific rules documented in the repository.
  • The current client bundles are source packages. Native Windows/macOS exports are not configured or tested.
  • The game uses direct TCP with TLS on port 12483; do not use a browser proxy or Cloudflare HTTP proxy for game traffic.
  • Player feedback is queued by the game service. Live GitHub issue publication is not a beta prerequisite.

The page's source revision and package hashes are published in downloads/release.json and downloads/SHA256SUMS.
